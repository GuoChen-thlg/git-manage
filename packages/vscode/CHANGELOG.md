# 更新日志

版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [0.0.1]

首个版本。

### 新增

- 侧边栏分支视图：本地与远程分组，单击筛选提交，右键切换/重命名/删除
- 侧边栏提交视图：点击定位到完整面板
- 完整面板：左侧 12 个操作图标、顶部搜索与多维过滤、提交图线、详情与行级差异
- 底部页签：控制台展示 git 命令日志，Worktrees 支持列出、新建、移除、清理
- 路径过滤的树状单选选择器，日期过滤的预设与自定义区间
- 统一日志系统，支持从命令面板打开输出通道

### 修复

- 从 GUI 启动时找不到 git 导致所有功能失效：启动时探测并补齐 PATH
- 提交历史查询失败时静默返回空列表：改为抛出带 stderr 的错误
