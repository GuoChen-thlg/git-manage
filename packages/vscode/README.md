# Git Manager for VS Code

在 VS Code 中提供 IntelliJ IDEA 风格的 Git 管理体验：分支树、提交图、差异对比与常用 git 操作。

## 功能

### 侧边栏

- **分支视图**：本地与远程分支分组展示，当前分支高亮
  - 单击分支只筛选下方提交列表，不会切换工作区分支
  - 切换分支请使用右键菜单，避免误触导致工作区文件变动
  - 右键支持切换、重命名、删除
- **提交视图**：展示提交历史，点击定位到完整面板

### 完整面板

按 `Cmd/Ctrl+J` 打开底部面板，选择 **Git Manager**，或执行命令 `Git Manager: 打开完整面板`。

- **左侧图标列**：12 个操作入口，涵盖新建分支、更新所选、删除分支、获取远程、收藏、定位、展开/折叠等
- **顶部工具栏**：搜索（支持正则与大小写）、按分支/用户/日期/路径过滤
- **提交列表**：分支图线、可配置显示列、多种排序模式
- **提交详情**：完整元信息、变更文件列表、可展开的行级差异
- **底部页签**
  - 控制台：展示扩展执行过的 git 命令与耗时，便于排查
  - Worktrees：列出、新建、移除、清理失效项

## 使用前准备

需要本机已安装 `git`。

从 Dock 或应用图标启动 VS Code 时，系统的 `PATH` 往往不包含 Homebrew 等目录。本扩展会在启动时自动探测常见安装位置（`/usr/bin`、`/opt/homebrew/bin`、`/usr/local/bin`），找到后自动补齐，无需手动配置。

如果仍然提示找不到 git，可在输出面板选择 **Git Manager** 查看详细日志，或执行命令 `Git Manager: 显示日志`。

## 命令

| 命令 | 说明 |
| --- | --- |
| `Git Manager: 打开完整面板` | 聚焦底部面板中的完整界面 |
| `Git Manager: 刷新` | 重新读取分支与提交 |
| `Git Manager: 新建分支` | 创建分支，可选择是否立即检出 |
| `Git Manager: 切换分支` | 从列表中选择并切换 |
| `Git Manager: 删除分支` | 删除分支，未合并时会二次确认 |
| `Git Manager: 重命名分支` | 重命名分支 |
| `Git Manager: 显示日志` | 打开日志输出通道 |

## 设计取舍

**单击分支不切换**：分支切换会改动工作区文件，误触代价较高。因此单击只做筛选，切换需要显式通过右键菜单或命令触发。

**路径过滤为单选**：与 IntelliJ IDEA 的行为一致，一次只按一个路径过滤。

**提交数量上限**：默认加载全部历史，但设置 20000 条的安全上限，避免超大仓库一次性拉取导致界面卡顿。达到上限时会写入警告日志。

## 反馈

遇到问题请附上 `Git Manager: 显示日志` 的输出，其中包含完整的命令执行记录与错误信息。
