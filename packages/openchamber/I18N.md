# 多语言支持（i18n）

Git 管理面板的全部界面文案（侧栏 tooltip、右键菜单、对话框、空态占位、相对时间等）
均通过 `panel/i18n.ts` 的字典翻译，不硬编码任何语言文案。

## 支持的语言（12 种）

| locale | 语言 | locale | 语言 |
| --- | --- | --- | --- |
| `en` | English | `es` | Español |
| `zh-CN` | 简体中文（默认） | `pt-BR` | Português (Brasil) |
| `zh-TW` | 繁體中文 | `ko` | 한국어 |
| `de` | Deutsch | `pl` | Polski |
| `fr` | Français | `ja` | 日本語 |
| `uk` | Українська | `tr` | Türkçe |

## 工作机制

- **语言选择**：宿主启动时通过 `setLocale(context.locale)` 传入系统语言，
  `resolveLocale` 会归一化到上表 12 种之一（如 `pt` → `pt-BR`，未知语言回退 `en`）。
- **取文案**：组件内一律调用 `t('key')`；带参数用 `t('key', { name: 'xxx' })`
  （占位符写作 `{name}`）。
- **回退链**：当前语言缺失 → 简体中文 → key 本身。
- **日期格式化**：使用 `getLang()` 返回的 BCP 47 tag，
  如 `date.toLocaleDateString(getLang())`，勿硬编码 `'zh-CN'`。

## key 命名约定

按 UI 域划分前缀：

- `sidebar.*` 侧栏图标 tooltip
- `branch.*` 分支操作与分支面板（含分组名、搜索占位）
- `commit.*` 提交列表（含搜索占位、空态）
- `dialog.*` 对话框（标题、按钮、说明、placeholder）
- `filter.*` 工具栏过滤与路径选择
- `file.*` / `diff.*` 文件差异面板
- `detail.*` 提交详情字段
- `time.*` 相对时间（`刚刚` / `{n}分钟前` 等）
- `reset.*` / `goto.*` / `sort.*` / `settings.*` / `batch.*` 专项功能

## 新增一条文案

1. 在 `panel/i18n.ts` 的 **12 个语言块**中各加一行（放在对应域的 key 附近）：

   ```ts
   'dialog.myLabel': 'My label',
   ```

2. 组件中使用 `t('dialog.myLabel')`；模板字符串内插值：

   ```ts
   html`<div>${t('dialog.myLabel')}</div>`;
   ```

3. 跑测试确认 key 在所有语言块都存在（`pnpm -C packages/openchamber test`）。

## 新增一种语言

1. 在 `i18n.ts` 底部新增语言块 `const xx: Record<string, string> = { ... }`，
   key 集合与 `en` 块完全一致（缺 key 会走回退链，但请补全）。
2. 把 `xx` 加入 `LocaleKey` 联合类型与 `dicts` 映射。
3. `resolveLocale` 无需改动（已按前缀泛化匹配）。

## 注意事项

- 界面可见文案（title / placeholder / 按钮文字 / 空态）禁止硬编码；
  `console.*` 日志与代码注释保持中文即可，不参与翻译。
- esbuild 产物中非 ASCII 字符会被转为 `\uXXXX` 转义，
  直接 grep 中文验证产物会误判，请按 key 名或解码后内容验证。
