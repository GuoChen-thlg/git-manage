## 2. A区域 - 分支面板 (左侧)

| 属性 | 描述 |

## 7. 交互流程详解

### 7.1 分支选择与过滤

**单击分支:**
```
→ 选中分支 (高亮显示)
→ 更新右侧面板内容:
  - B区域: 过滤显示该分支的提交列表
  - 显示分支过滤指示器: "分支: feature/login [✕]"
```

**双击分支:**
```
→ 选中分支
→ 加载该分支的提交历史
→ 更新提交列表 (B区域)
→ 显示分支过滤条
```

**清除过滤:**
```
→ 点击过滤条的 ✕ 按钮
→ 或点击刷新按钮
→ 恢复显示所有提交
```

### 7.3 分支切换 (Checkout)

**场景1: 干净工作区**
```
用户点击分支 → 选择 Checkout
→ 直接切换
→ 底部通知: "已切换到分支 feature/login"
→ 自动恢复上下文
```

**场景2: 有未提交更改 (不冲突)**
```
用户点击分支 → 选择 Checkout
→ 直接切换 (保留本地更改)
→ 底部通知: "已切换到分支 feature/login"
```

**场景3: 有未提交更改 (冲突)**
```
用户点击分支 → 选择 Checkout
→ 弹出对话框:
┌─────────────────────────────────────────┐
│ Checkout 分支                            │
│                                          │
│ 以下文件将被覆盖:                        │
│   src/main.ts                            │
│   src/utils.ts                           │
│                                          │
│ [Force Checkout] [Smart Checkout] [Cancel]│
└─────────────────────────────────────────┘

Force: 覆盖本地更改
Smart: Shelve → 切换 → Unshelve (可能冲突)
```

### 7.4 分支删除

```
用户右键分支 → Delete
→ 确认对话框:
┌─────────────────────────────────────────┐
│ 删除分支?                                │
│                                          │
│ 确定要删除 "feature/old" 吗?            │
│ 该分支有 3 个未合并的提交。             │
│                                          │
│ [删除]  [取消]                           │
└─────────────────────────────────────────┘

删除后通知:
┌─────────────────────────────────────────┐
│ 分支 "feature/old" 已删除               │
│ [恢复]  [查看未合并提交]                │
└─────────────────────────────────────────┘
```

### 7.5 提交搜索

```
用户在搜索框输入关键词
→ 实时过滤提交列表
→ 高亮匹配的提交
→ 按 Enter 跳转到下一个匹配
```

### 7.6 文件差异查看

```
用户在提交列表选择提交
→ C区域显示变更文件列表
→ 用户点击文件
→ D区域显示差异详情
→ 支持 Side-by-side 和 Unified 视图
```
