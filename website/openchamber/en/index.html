Five features,
all packed into one panel.

Every interaction polished against a mature IDE as the benchmark — not our invention, we just had a very good teacher.

Branch management

Browse local and remote branches in grouped trees, star the ones you use daily. Positions are recorded before deletion so a mis-click is one button away from undone, unmerged branches get a clear warning, and the current branch is locked against accidents.

Commit history

Commit list, commit graph, and commit details, plus cherry-pick, revert, and stash — the handful of moves you make a hundred times a day, all within arm's reach.

Diff viewer

File-level and commit-level diffs, with visual staging that actually makes sense. What changed, and whether it belongs in the index — clear at a glance.

Smart filtering

Combine case, regex, branch, author, date, and path filters. Paths support IDEA-style tree multi-select, so even in a huge monorepo you land on the right commit in seconds.

12 UI languages

Twelve languages built in. Strings and date formats follow your system language automatically — zero configuration required.

Deleted branches come back

The branch's location is recorded before deletion, then restored with one click straight from the notification. Butterfingers welcome.

Three ways to install.

Install from OpenChamber's Settings → Extensions. Any one of these will do.

Install from ZIP

Download the matching git-manager-[version].zip from the releases page, pick the file in Settings, or just drag it straight into the install area.

02

Install from a folder (local development)

Start the build watcher first so code changes rebuild artifacts automatically, then select the packages/openchamber directory. Without a build you'll get a missing-build prompt.

pnpm install && pnpm dev
03

Install from a Git URL

Paste the repository URL and the host shallow-clones it before installing (the repo must already contain the build artifacts). #release points at the release branch where the artifacts live.

https://github.com/GuoChen-thlg/git-manage.git#release

FAQ.

Can I install straight from the source branch?

No. The panel and services are build artifacts and don't get committed along with the source branch. Use the ZIP, a local build folder, or the #release branch instead.

Do I need git installed on my machine?

Yes. The extension runs local git commands through the host's exec permission, so without git installed, those actions will fail.

Which operating systems are supported?

Cross-platform. If OpenChamber can run and git is installed, Windows, macOS, and Linux all work.

Will this make me look more professional?

The moment that commit graph starts rolling, your coworkers will swear you just came back from a stint at some big-tech company. We don't guarantee promotions — we do guarantee it looks good.
