分支管理

本地与远程分组浏览、收藏常用分支。删除前自动记录位置，误删一键还原；未合并明确提醒，当前分支锁定防误操作。

提交历史

提交列表、提交图、提交详情，外加 cherry-pick、revert、stash——日常最高频的那几步都在手边。

差异对比

文件级与提交级差异，直观的暂存区管理。改了什么、要不要进暂存，一眼看清。

智能过滤

大小写、正则、分支、作者、日期、路径组合过滤，路径支持 IDEA 风格树形多选，大仓库里也能秒级定位。

多语言界面

内置 12 种语言，文案与日期格式随系统语言自动切换，无需手动设置。

误删可还原

删除分支前记录位置，删除后从通知里一键找回。手滑不背锅。

三种安装方式，
总有一款逃不掉。

在 OpenChamber 的「设置 → 扩展」里装，任选其一。

01

从 ZIP 安装

下载对应版本的 git-manager-[version].zip，在设置中选择该文件，或直接拖进安装区域。

前往 Releases 下载 →
02

从文件夹安装（本地开发）

先启动构建监听，代码改动自动重建产物，再选择 packages/openchamber 目录。没有产物会提示 missing-build。

pnpm install && pnpm dev
03

从 Git URL 安装

填入仓库地址，宿主浅克隆后安装（仓库需已包含构建产物）。#release 指向存放产物的发布分支。

https://github.com/GuoChen-thlg/git-manage.git#release

常见问题。

源码分支能直接安装吗？

不能。面板与服务是打包产物，不随源码分支提交。请使用 ZIP、本地构建目录，或 #release 发布分支。

需要本机安装 git 吗？

需要。扩展通过宿主的 exec 权限调用本机 git 命令，未安装时相关操作会失败。

支持哪些系统？

跨平台。只要 OpenChamber 能跑、本机有 git，Windows、macOS、Linux 都行。

会让我看起来更专业吗？

提交图一滚起来，同事会以为你刚从大厂进修回来。我们不保证升职，但保证好看。
