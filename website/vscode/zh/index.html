分支管理

本地与远程分组浏览、收藏常用分支。删除前自动记录位置，误删一键还原；未合并明确提醒，当前分支锁定防误操作。

提交历史

提交列表、提交图、提交详情，外加 cherry-pick、revert、stash——日常最高频的那几步都在手边。

差异对比

文件级与提交级差异，直观的暂存区管理。改了什么、要不要进暂存，一眼看清。

智能过滤

大小写、正则、分支、作者、日期、路径组合过滤，路径支持 IDEA 风格树形多选，大仓库里也能秒级定位。

多语言界面

内置 12 种语言，文案与日期格式随系统语言自动切换，无需手动设置。

误删可还原

删除分支前记录位置，删除后从通知里一键找回。手滑不背锅。

常见问题。

源码分支能直接安装吗？

不能。扩展需要打包后的产物，源码分支里没有。请从 Marketplace 安装，或下载 VSIX 走「从 VSIX 安装」。

需要本机安装 git 吗？

需要。扩展在扩展宿主进程里调用本机 git 命令，未安装时相关操作会失败。

支持哪些系统？

跨平台。只要 VS Code 能跑、本机有 git，Windows、macOS、Linux 都行。

和 OpenChamber 版是什么关系？

同一个插件的两个宿主版本，功能对齐、同步维护。VS Code 版给天天开着 VS Code 的人，OpenChamber 版给另一边的同事——两边打同一场仗。
