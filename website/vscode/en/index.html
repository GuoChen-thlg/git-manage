Six capabilities,
one side panel handles them all.

Interaction details polished against a mature IDE as the benchmark — not our originality, the benchmark just teaches well.

Branch management

Browse local and remote branches grouped and starred. Position is recorded before every delete so a mis-click is one restore away; unmerged branches are clearly flagged and the current branch is locked against accidents.

Commit history

Commit list, commit graph and commit details, plus cherry-pick, revert and stash — the handful of moves you make every day, all within reach.

Diff comparison

File-level and commit-level diffs with straightforward staging. What changed, and whether it belongs in the staging area — visible at a glance.

Smart filtering

Combine case, regex, branch, author, date and path filters; paths support IDEA-style tree multi-select, so you locate things in seconds even in large repositories.

Multilingual UI

12 built-in languages; copy and date formats switch with your system locale automatically — no manual setup.

Deletes are recoverable

The branch position is recorded before deletion and a one-click restore shows up in the notification. Slips of the hand don't have to be your problem.

FAQ.

Can I install straight from a source branch?

No. The extension needs packaged build artifacts, which source branches don't ship. Install from the Marketplace, or download the VSIX and use Install from VSIX.

Do I need git installed locally?

Yes. The extension invokes your local git binary from the extension host process; without git on your PATH, those operations fail.

Which operating systems are supported?

Cross-platform. As long as VS Code runs and git is installed, Windows, macOS and Linux all work.

How does this relate to the OpenChamber edition?

Same plugin, two host versions — feature parity, maintained side by side. The VS Code edition is for people who keep VS Code open all day; the OpenChamber edition is for the folks on the other side. Same fight, different window.
