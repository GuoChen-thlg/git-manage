# Git Manage

[![CI](https://github.com/GuoChen-thlg/git-manage/actions/workflows/ci.yml/badge.svg)](https://github.com/GuoChen-thlg/git-manage/actions/workflows/ci.yml)
![version](https://img.shields.io/badge/version-0.0.1-blue)
![license](https://img.shields.io/badge/license-Apache%202.0-blue)

Багатоплатформний графічний інструмент керування Git, що постачається як розширення [OpenChamber](https://docs.openchamber.dev/sdk/). Дизайн взаємодії близько наслідує вікно Git в IntelliJ IDEA, тож розробники, звиклі до Git-процесів у стилі IDE, можуть одразу почати роботу: звичне керування гілками, перегляд комітів і порівняння різниць — будь-де.

## Можливості

- **Керування гілками**: Перегляд локальних і віддалених гілок за групами, додавання улюблених; створення, перейменування, перемикання й видалення в один клік. Позиція гілки зберігається перед видаленням, тож випадкове видалення можна скасувати прямо зі сповіщення. Незлиті гілки чітко позначаються, а поточна гілка заблокована від помилкових дій
- **Історія комітів**: Список комітів із графом і деталями; типові операції — cherry-pick, revert, stash
- **Порівняння різниць**: Перегляд різниць на рівні файлів і комітів, зручне керування індексом
- **Розумна фільтрація**: Комбінування фільтрів за регістром, регулярним виразом, гілкою, автором, датою та шляхом; шляхи підтримують деревоподібний множинний вибір у стилі IDEA
- **Багатомовний інтерфейс**: 12 вбудованих мов, зокрема китайська, англійська, японська, корейська, німецька та французька; тексти й формати дат автоматично відповідають мові системи, див. [примітки щодо i18n](packages/openchamber/I18N.md)

## Плани

- Позбавити професійну візуалізацію Git прив'язки до конкретного редактора — зручна робота з гілками й комітами в будь-якому середовищі
- Розвивати ключові можливості самостійно та поступово виводити їх на OpenChamber, VSCode та інші платформи
- Продовжувати шліфувати деталі взаємодії, орієнтуючись на зрілі IDE, щоб кожен клік був інтуїтивним
- Відкритий код — запрошуємо до участі
